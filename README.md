# Robot de Sumo Controlado por Smartphone con Sistema de Lanzamiento de Agua

## Descripción del proyecto

Este proyecto consiste en el diseño y construcción de un robot tipo sumo controlado inalámbricamente mediante un teléfono celular, utilizando un microcontrolador STM32F407 como unidad principal de control.

El robot contará con dos motores de corriente directa para su desplazamiento, una cuña frontal para empujar objetos u oponentes y dos sensores infrarrojos digitales para detectar los límites de la pista.

Adicionalmente, incorporará un sistema de lanzamiento de agua de baja presión, compuesto por un depósito, una minibomba y una boquilla fija. El usuario podrá activar este sistema mediante un botón desde su teléfono celular.

## Objetivo general

Diseñar e implementar un robot tipo sumo basado en STM32, capaz de desplazarse mediante control inalámbrico, regular sus motores, detectar los límites de una pista y activar un sistema complementario de lanzamiento de agua.

## Funciones principales

- Control inalámbrico mediante smartphone.
- Movimiento hacia adelante y atrás.
- Giro a izquierda y derecha.
- Regulación de velocidad mediante PWM.
- Detección de los bordes de la pista.
- Activación de una minibomba de agua mediante un botón.
- Paro de emergencia.

## Componentes propuestos

- Microcontrolador STM32F407.
- Módulo de comunicación inalámbrica.
- Dos motores DC con reductora.
- Driver de motores.
- Dos sensores infrarrojos digitales.
- Minibomba de agua.
- Depósito, manguera y boquilla fija.
- Batería recargable y reguladores.
- Chasis tipo sumo con cuña frontal.

## Etapas del proyecto

**Etapa 1:** Investigación, propuesta, viabilidad, arquitectura, presupuesto y planificación.

**Etapa 2:** Desarrollo y pruebas individuales de los módulos, integración inicial y construcción parcial del prototipo.

**Etapa 3:** Integración completa, pruebas de funcionamiento, presentación final y revisión del código fuente.
